# Project 2: NYUAD Comic Map

Group project (Megan, Sanjana, Tifi). An interactive comic where the NYU Abu Dhabi campus map is the menu.
Click a building to open its comic strip. Inspired by Emma Carroll's "Pretty Place" house map.

## Pages
- `index.html`: the campus map (C1, C2, C3, D1, D2, Palms, Dorms). Hovering a place colors it; all dorms light up together.
- `places/*.html`: one page per place with 5 placeholder panels (our comic strips go here).

## Layout prototype
- Map: SVG polygons drawn from our wireframe.
- Comic strip: flexbox.
